# ТаТиШот

A light screenshot tool for Windows. Press Print Screen, select an area, mark it up, then
copy, save, email or pin it on top of everything.

**[Get it from the Microsoft Store](https://apps.microsoft.com/detail/9NHB6DM76DQT)**

## Coming from GitHub?

ТаТиШот now updates from the Microsoft Store only. Version 0.25.0 is the last one here.

A copy installed from GitHub moves itself to the Store: it installs the Store copy without
asking, which accepts the Microsoft Store's terms on your behalf, then removes itself. Your
settings stay.

Where the Store isn't available, including Russia and Belarus, a copy stays on 0.25.0 and gets
no more updates.

[Privacy policy](PRIVACY.md) · [Questions and problems](https://github.com/Lexx2140/tatyshot-releases/issues)

позначте потрібне, а тоді скопіюйте, збережіть, надішліть поштою або закріпіть знімок поверх
усіх вікон.

**[Завантажити з Microsoft Store](https://apps.microsoft.com/detail/9NHB6DM76DQT)**

## Встановили з GitHub?

ТаТиШот тепер оновлюється лише з Microsoft Store. Версія 0.25.0 — остання тут.

Копія, встановлена з GitHub, сама переходить на Store: вона встановлює копію зі Store, не
питаючи, що приймає умови Microsoft Store від вашого імені, а тоді видаляє себе. Ваші
налаштування зберігаються.

Там, де Store недоступний, зокрема в Росії та Білорусі, копія залишається на версії 0.25.0 і
більше не отримує оновлень.
